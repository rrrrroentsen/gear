# 我的装备（MyGear）

记下自己的电子装备，看每一件的日均成本随着使用时间往下降。手机上添加到主屏幕后像 App 一样用，数据只存在自己的设备里。

版本 1.2.0。

## 能做什么

- **日均成本**：日均 = 总成本 ÷ 持有天数，购入当天算第 1 天。和原来 Excel 表的算法一致。
- **跳水图**：每件装备一张日均下降曲线，标出今天的位置、回本线、往后的走势；左右拖动可以看任意一天。
- **回本**：给装备定一个目标（用满几年，或者日均降到多少），日均降到目标以下就算回本。
- **服役中 / 已退役 / 已卖出**：退役后日均定格；卖出后按「(总成本 − 卖出价) ÷ 持有天数」算实际日均。
- **追加花费**：配件、维修、延保记到对应的装备上，计入总成本。
- **美元录入**：录入金额时点一下货币符号，按外币填，自动按汇率换算。
- **时间线和里程碑**：服役满 1000 天、日均跌破 ¥5、回本……已经达成的和一年内将要到来的。
- **心愿**：想买的东西先放着，看它要用多久才回本。买了以后一键转成装备。
- **自定义顺序**：在列表或贴纸墙里按住一件装备不动，等它浮起来以后拖到想要的位置。列表里排序方式选「自定义顺序」时，每行右边还有一个手柄，按住手柄可以马上拖。列表和贴纸墙是同一个顺序，存在本机，也会跟着备份走。
- **类别和边框颜色**：可以自己建类别（比如「外设」「游戏设备」），勾选哪些装备属于它，给每个类别挑一个颜色，这个类别的贴纸外面那一圈边就是这个颜色。边的粗细有细、标准、粗三档。
- **图标**：五百多个表情按类别分好了组（数码、影音、玩具、家居、厨房、出行、穿戴……），也可以自己输入别的表情。
- **贴纸墙**：装备显示成贴纸。可以用照片做贴纸，白底的产品图会自动去掉背景。
- **备份**：备份文件或备份码，换手机、换浏览器时用。

## 部署到 GitHub Pages

和「家务打卡」的做法一样，只是这次不需要 Google 表格和 Apps Script。

1. 打开 github.com，右上角 **+** → **New repository**。Repository name 填 `gear`（全小写），选 **Public**，点 **Create repository**。
2. 在新仓库页面点 **uploading an existing file**（或者 **Add file → Upload files**）。把这个文件夹**里面的全部文件**选中拖进去（拖文件，不是拖文件夹），点 **Commit changes**。
3. 仓库的 **Settings → Pages**。Source 选 **Deploy from a branch**，Branch 选 `main` 和 `/ (root)`，点 **Save**。
4. 等一两分钟，刷新这个页面，顶部会出现地址。用户名是 `rrrrroentsen` 的话，地址就是
   `https://rrrrroentsen.github.io/gear/`

仓库是公开的，但里面只有代码，没有任何个人数据。

## 在 iPhone 上安装

1. 用 **Safari** 打开上面的地址。
2. 点底部的分享按钮 → **添加到主屏幕**。
3. 从主屏幕打开「我的装备」，点 **粘贴导入码 / 恢复备份**，把导入码粘贴进去，点 **导入**。

主屏幕上的 App 和 Safari 里的网页是两份互不相通的数据，所以导入要在主屏幕的 App 里做。微信里打开的网页不能添加到主屏幕，要先在 Safari 里打开。

电脑上直接用浏览器打开同一个地址就能用。手机和电脑的数据各存各的，不会自动同步；要搬数据就在一边「备份」、另一边「恢复 / 导入」。

## 备份

数据存在这台设备的这个浏览器里。下面几种情况会丢，事先备份一下：

- 换手机，或者把主屏幕上的 App 删掉重新添加
- 在 iPhone 的设置里清除了 Safari 的网站数据
- 只在 Safari 里用（没有添加到主屏幕），并且连续 7 天没打开过

**设置 → 备份**里有两种方式：

- **保存备份文件**：手机上会弹出分享面板，选「存储到文件」。备份文件里包含照片贴纸。
- **复制备份码**：一段以 `MG1.` 开头的文字，粘贴到备忘录或者发给自己都行。备份码里没有照片。

恢复时在 **设置 → 恢复 / 导入** 里粘贴备份码或者选备份文件。已经有数据时可以选「合并进来」或「换成这份」；换错了可以在设置里撤销一次。

也可以从表格导入：在 Excel 或 Google 表格里选中带表头的几行（表头里要有「名字」「购买时间」「购入金额」），复制，粘贴到同一个输入框里。

## 升级

以后拿到新版本的文件：在仓库里 **Add file → Upload files**，把新文件拖进去覆盖同名文件，提交。不用动数据，也不用重新添加到主屏幕。

手机上把 App 从后台划掉再打开就是新的。GitHub Pages 自己有大约 10 分钟的缓存，刚传完看到的可能还是旧的。**设置 → 关于**里能看到当前版本号。

## 数据和隐私

- 页面不向任何第三方发请求，也没有统计代码。所有计算都在本机完成。
- 同一个 GitHub 账号下的网页应用（飞行图、家务打卡）共用同一个域名，本机存储也在同一个地方。这个应用只读写名字以 `mygear:` 开头的条目和名字以 `mygear-` 开头的缓存，不碰别的。
- 照片贴纸缩小后存在本机，不会上传。

## 口径

- 持有天数 = 截止日 − 购入日 + 1，最少 1 天。服役中的截止日是今天；已退役、已卖出的截止日是退役、卖出那天。
- 日均 = 总成本 ÷ 持有天数；总成本 = 购入金额 + 追加花费。
- 已卖出的实际日均 =（总成本 − 卖出金额）÷ 持有天数。
- 回本：日均 ≤ 目标日均。「用满 N 年」等价于目标日均 = 总成本 ÷（N × 365）。
- 合计只算服役中的装备。标了「大件」的（比如汽车）可以选择不算进合计。
- 「今天」取设备本地的日期。过了半夜 12 点会自动按新的一天重算。

## 常见问题

**打开还是旧版。** 把 App 从后台划掉重开；刚上传完的话等几分钟。

**数据不见了。** 多半是上面「备份」里说的几种情况之一。用备份恢复。

**主屏幕图标或名字想换。** 换掉 `icon-*.png` 或改 `manifest.webmanifest` 里的名字后，要把主屏幕上的 App 删掉重新添加。删之前先备份，重新添加后再导入。

**想改默认的回本目标。** 设置 → 怎么算。单件装备的目标在它的详情页里改。

**怎么调整装备的顺序。** 在装备列表里按住一件不动，大约半秒后它会浮起来（出现一圈黑边），这时上下拖到想要的位置再松手。第一次拖完，排序方式会自动变成「自定义顺序」，每行右边多出一个三条横线的手柄，以后按住手柄就能直接拖。想回到按日均排，在排序菜单里换回去就行，排好的顺序不会丢，再选「自定义顺序」还在。

贴纸墙上也一样：按住一个贴纸约半秒，等它浮起来，拖到另一个贴纸上。压在那个贴纸的左半边松手，它就排到那个贴纸前面；压在右半边，就排到后面。别的贴纸会自己让开、重新排好。贴纸墙是按顺序一行一行排的，不能把贴纸随手摆在任意位置。列表和贴纸墙用的是同一个顺序。

不想拖的话，点一下手柄，会出来「移到最前面 / 上移一位 / 下移一位 / 移到最后面」几个按钮。电脑上还可以用键盘：按 Tab 把焦点移到手柄上，再按上下方向键。

**排序菜单选了别的方式以后拖不动了。** 这是有意的：已经排过自定义顺序以后，只有在「自定义顺序」下才能拖，免得不小心把排好的顺序冲掉。

**怎么给贴纸换边框颜色、怎么自己建类别。** 贴纸墙上面（或者列表最下面）有一个「类别和边框」，设置里也有入口。进去以后：

- 最上面选边框的粗细：细、标准、粗。
- 「新建类别」：起个名字，挑一个颜色，在下面的清单里勾上属于这个类别的装备，保存。一件装备只属于一个类别。
- 点已有的类别可以改名字、换颜色、增减装备，或者删除。把一个类别改成和另一个同名，两个就合并了。
- 颜色有八个预设色（蓝、橙、青绿、黄、粉、绿、紫、红，深色模式下会自动换成深色底上看得清的那一档）。最右边彩色的那一格是自定义：点它会弹出系统的取色器，也可以在「色号」里直接填 `#RRGGBB`。
- 「一键配色」会给还没有颜色的类别依次分配预设色。预设色只有八个，类别更多的话剩下的要自己挑。
- 没有类别、或者类别没设颜色的贴纸，边是白色的；这个默认颜色也可以换。

**金额想用美元记账。** 设置 → 记账货币。已有的金额不会自动换算。
